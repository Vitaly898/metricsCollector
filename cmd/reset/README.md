# reset

Генератор методов `Reset()` для структур с комментарием `// generate:reset`.
Пример использования в проекте — `Metrics` в `internal/model`.

Запуск из корня проекта:

```sh
go run ./cmd/reset
```

Для другого корневого каталога:

```sh
go run ./cmd/reset -dir /path/to/module
```

Утилита сканирует пакеты по шаблону `./...` от выбранного каталога с учётом
текущих настроек сборки Go. Зависимости, вложенные Go-модули, `vendor`, `testdata`
и файлы `_test.go` в генерацию не входят.

Метка ставится непосредственно над объявлением типа или над типом внутри
группы `type (...)`:

```go
// generate:reset
type Item struct {
    Name   string
    Count  *int
    Values []string
    Labels map[string]string
    Child  *Item
}
```

Методы всех отмеченных структур пакета записываются в его `reset.gen.go`.
У метода указательный receiver; вызов на `nil` ничего не делает.

| Тип поля | Действие |
| --- | --- |
| Число, строка, bool | Нулевое значение |
| Слайс | Длина становится нулевой; память и ёмкость сохраняются |
| Мапа | `clear`; сама мапа сохраняется |
| Указатель | Если не `nil`, значение под ним сбрасывается по тем же правилам; адрес сохраняется |
| Структура с `Reset()` | Вызывается её метод, включая метод с указательным receiver |
| Структура без `Reset()` | Обнуляется целиком |
| Массив | Каждый элемент сбрасывается по своему типу |
| Интерфейс, функция, канал, `unsafe.Pointer` | `nil` |

Нулевые указатели, слайсы и мапы не выделяются. Поддерживаются именованные типы,
встраивание и структуры из других пакетов. Для полей типа параметра обобщённой
структуры генерируется вспомогательная функция на `reflect`, которая применяет
эти же правила к фактическому типу; обычные поля сбрасываются прямым кодом.
Вспомогательная функция используется также для рекурсивных типов указателей.

Уже написанный вручную метод `Reset()` сохраняется и не дублируется. Несовместимая
сигнатура такого метода, метка над псевдонимом или конфликт с полем `Reset`
приводят к ошибке до записи файлов.

Повторный запуск при неизменённых исходниках не меняет сгенерированные файлы.
При изменении полей методы обновляются; при удалении всех меток остаётся файл
с заголовком генератора и объявлением пакета, без старых методов. Чужой файл
`reset.gen.go` утилита не перезаписывает.

Проверки генератора:

```sh
go test -race ./cmd/reset
```

Тесты создают отдельные Go-модули, генерируют методы и запускают проверки
поведения полученного кода с детектором гонок.
