# linter

Статический анализатор на основе `golang.org/x/tools/go/analysis/singlechecker`.

Запуск из корня проекта:

```sh
go run ./cmd/linter ./...
```

Анализатор проверяет исходники и тесты выбранных пакетов:

- запрещает вызовы встроенной функции `panic` во всех функциях, включая `main`;
- запрещает прямые вызовы `log.Fatal`, `log.Fatalf`, `log.Fatalln` и `os.Exit`
  вне функции `main` пакета `main`.

Анонимная функция внутри `main` считается отдельной функцией и не получает
исключения. Функция `main` другого пакета и метод с таким именем тоже не получают
исключения. Импорты с псевдонимами и точкой учитываются; одноимённые пользовательские
функции, затенённые имена, методы `testing.T` и `log.Logger` не вызывают диагностику.
Косвенные вызовы через переменные функционального типа не отслеживаются.

Тесты с ожидаемыми диагностиками находятся в `testdata` и запускаются через
`golang.org/x/tools/go/analysis/analysistest`:

```sh
go test ./cmd/linter
```

Go исключает каталог `testdata` из шаблона `./...`; примеры нарушений проверяются
только при запуске тестов анализатора.
